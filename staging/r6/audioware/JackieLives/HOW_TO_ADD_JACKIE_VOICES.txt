Jackie Lives — Jackie's voice
=============================

YOU DON'T HAVE TO DO ANYTHING. (New in v1.66.)

Jackie speaks in his real voice out of the box. Not a copy, not an
imitation — the actual recordings that are already sitting in your
Cyberpunk 2077 installation, played by the game itself, on cue.

If you followed the old instructions in this file, thank you for your
patience, and sorry: you no longer need any of it. There is nothing to
extract, nothing to convert, nothing to rename, and no 940 MB of audio
to manage.


WHAT YOU NEED
-------------
  - Cyber Engine Tweaks, Codeware   (the mod's normal requirements)
  - redscript                        <- this is what plays his voice

That's the whole list. redscript is a standard Cyberpunk modding
requirement that most modded games already have.

You do NOT need: Audioware. WolvenKit. ffmpeg. Python. A tutorial.


WHAT IF HE'S SILENT?
--------------------
1. Check that this file exists in your game folder:
       ...\Cyberpunk 2077\r6\scripts\JackieLives\JackieLivesVO.reds
   If it's missing, the mod was installed incompletely — re-extract the
   zip and make sure the "r6" folder went in alongside "bin".

2. Check that redscript is installed. If other redscript mods work, it is.

3. Open the CET console and look for the line starting "[JackieLives] [VO]"
   in the log. It says which of the three it's using:
       "using the game's OWN voice-over"   <- correct
       "using the Audioware bank"          <- the old path; the shim didn't load
       "no voice backend"                  <- redscript or the .reds is missing

He is never *broken* when silent — subtitles always work, and he still
makes his own vocal efforts. It just isn't the good version.


AUDIOWARE LOG FULL OF "cannot load audio: jackie_..." ERRORS?
-------------------------------------------------------------
That is this folder's fault, and v2.0 fixes it.

Up to v1.8.10 the mod shipped a manifest (JackieLives.yml) that listed all
1200-odd of Jackie's clips by name. If you never built a voice bank — and
since v1.66 nobody needs to — those .Wav files aren't on your disk, so
Audioware logged a validation error for every single one of them at every
startup. Noisy, and completely harmless: it never affected Jackie's voice,
which comes from the game's own recordings via redscript.

The manifest is no longer shipped. To clear the spam for good, delete:

    ...\Cyberpunk 2077\r6\audioware\JackieLives\JackieLives.yml

(If that file is gone already, you're done — nothing else in this folder
talks to Audioware.)

Deleting it costs you nothing unless you personally built a voice bank.
If you DID build one, keep your .Wav files where they are and regenerate a
manifest that matches exactly what you have:

    python rebuild_bank_yml.py

(that script is in this folder). It only ever lists files that are really
there, so it can't produce these errors.


ABOUT THIS FOLDER (r6\audioware\JackieLives)
--------------------------------------------
This is the old voice system. It still works, so nobody who built a bank
loses it — the mod prefers the new path and falls back to this one. If you
never built a bank, this folder does nothing at all and you can ignore it.

It will be removed in a future version.
